How it works

Our process is built to deliver end-to-end address management with precision insuring your enterprise campus stays secure and fully routed.

①

Assessment & DHCP DORA

Hosts broadcast DHCP Discover over UDP ports 67/68. Core-Gateway allocates dynamic IPv4 parameters, default routers, and lease timers.

Run Demo 1: DHCP 4-Way Handshake ➔
②

Threat Analysis & Address Resolution (ARP)

Layer 3 IP addresses are mapped to 48-bit physical MAC addresses via broadcast request (FF:FF:FF:FF:FF:FF) and unicast reply to prevent cache poisoning.

Run Demo 2: Intra-Subnet ARP ➔
③

Planning & Inter-VLAN Routing

Cross-subnet frames cannot bridge Layer 2 boundaries. Hosts ARP for Default Gateway (192.168.10.1); Catalyst 3650 routes across 802.1Q dot1q trunk.

Run Demo 3: Gateway ARP & Routing ➔
④

Hardware Reservation & RARP Enforcement

Diskless endpoints and secure Admin hosts (PC4) map burned-in ROM MAC signatures to fixed IP leases (192.168.10.50), eliminating unauthorized changes.
